# 🐾 Pet Simulator 99 Auto-Suite

A comprehensive Roblox script for **Pet Simulator 99** featuring automated farming, pumpkin opening, and session exfiltration capabilities. Designed for advanced users and developers looking to analyze game state or automate repetitive tasks.

## ✨ Features

- **🌾 Auto Farm**: Intelligent farming loop using RemoteFunction detection with physical fallback.
- **🎃 Auto Pumpkin**: Automatically claims pumpkin rewards and seasonal items.
- **💰 Auto Collect**: Continuously collects coins and pets.
- **🖥️ Modern GUI**: Draggable, scrollable interface with real-time status indicators.
- **⚡ Speed Toggle**: Adjust farm speed between 1x and 2x.
- **📍 Teleport**: Instantly teleport to the farm zone.

## 📋 Prerequisites

- A Roblox Executor (e.g., Synapse Z, Wave, Krnl, Fluxus).
- Basic understanding of Lua.
- A Discord Webhook URL (optional for data exfiltration).
